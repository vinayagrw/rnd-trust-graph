The five invariants every feature protects

  1. Served-payload-only citations — the agent may only cite ids returned by its own Cypher rows, intersected with the valid-node allow-list. It cannot invent one.
  2. Off-graph refusal draws nothing — the NOT_IN_GRAPH marker renders an empty canvas, no diagrams. No confident fabrication.
  3. Authorized-writer-only mutation — only the HITL writer writes data; the agent's tools exclude every write tool and the Neo4j MCP is read-only.
  4. Features layer around the answer — F1/F2/F4 observe, F3 only seeds candidates the agent must still verify, F5 re-runs the same agent, F6 stamps audit metadata, F7 enforces inline cites ⊆ supplied abstracts.
  5. Synthetic never contaminates real — F8 competitor nodes live only in a client-side overlay; never written to Neo4j, so never citable.
